# Mitsugen Installer WIP 🚧 practically archived 🚨 
A shell script to install mitsugen. 

I decided to make an install script for [mitsugen](https://github.com/DimitrisMilonopoulos/mitsugen), using Google Gemini's advice on how to install it on Debian 13 and Fedora 43.

Note: VERY BADLY MAINTAINED. Also, probably isn't comprehensive, I don't know what state it is in. I do not recommend using mitsugen as in my experience it is outdated and has issues but I did manage to get it to kind of work with a lot of tweaking.

Run script: 

```shell
curl -fsSL https://raw.githubusercontent.com/parryo02/mitsugen-installer/main/install-mitsugen.sh | bash
```
